# Boujee Brush-worx Website

Custom Next.js website starter for Boujee Brush-worx.

## Run locally
npm install
npm run dev

## Build
npm run build

## Included
- Premium black, cream and gold branding
- SEO metadata
- LocalBusiness schema
- FAQ schema
- Sitemap
- Robots.txt
- Service pages
- Knowledge Centre
- Estimate request page
- Private staff estimator placeholder
